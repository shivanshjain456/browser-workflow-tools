# G-13 / G-85 acquisition correction — design before implementation

Evidence: `audit/evidence/manager-lab/vm-before-fixes.json`, exact artifact0b2b1b50..., actual official Violentmonkey2.49.0 MV3 / Chrome155.0.8059.84, normal file-import UI and Chrome Allow User Scripts switch. No fake GM bindings. Same-origin converted PNG and original succeed; cross-origin PNG succeeds through manager; cross-origin original fails; strict image CSP rejects both. Actual saved PNG independently pixel-equal before original-output test was added. Manager-stored script SHA equals distributed artifact.

G-85: source acquired() caches raw Uint8Array, but documented getBytes() returns a `{bytes,mime}` record and convert.getOriginalBytes expects that record. The manager-fetched raw bytes are consequently ignored for original/inspection/animation workflows. This is a confirmed additional S1 fidelity fault, not a missing codec. Two approaches: (A) teach every consumer to accept ambiguous bytes-or-record; (B) honour the acquisition contract and provide the already-supported bytes fast path. Choose B: one structured cache, raw `.bytes` only for already-held bytes; no additional request and no newly published page handle.

G-13: (A) rewrite CSP/require blob/data allowlists via extension privileges; (B) keep current HTML-image decode first (preserves ordinary pixels) and use createImageBitmap on already-acquired bytes after an image decode failure. Choose B. Never weaken response headers, fetch remote executable code or grow grants. Each new ImageBitmap lease must close exactly once on release/failure/timeout/abort, including late completion. Old/unsupported browsers retain explicit decode failure, not a false success. GIF/EXIF default decoding and colour conversion are unchanged on the original successful path. A full wide-gamut/metadata implementation is separate.

Data URLs decode locally into bytes only after existing HTML decode fails; no fetch(data:) under connect-src none. Inline SVG serialisation is factored into a Blob helper preserving original XML bytes; legacy URL helper delegates. Browser SVG bitmap support is tested rather than assumed. Hostile SVG remains an image decode, not executable DOM insertion.

Verification: unit lease lifecycle/late-close/abort and local data parser cases; unchanged original golden bytes; full units/lint/browser; real-manager same/cross/strict-CSP converted and original outputs. Snapshot before changes permits a grouped independently reversible patch; raster/source changes form one acquisition-contract group and depend on no new setting/grant/runtime dependency. No release-acceptance flag is changed merely because these tests pass.
