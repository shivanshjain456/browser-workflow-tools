# Credits & Technical Acknowledgments

This project is built from scratch by **Shivansh Jain** and relies on open web standards, browser userscript managers, and public preservation initiatives:

---

## Web Standards & Specifications

- **ECMA-262 / ECMAScript:** Modern JavaScript standards enabling native async/await, Sets/Maps, and Web APIs without heavy external runtimes.
- **W3C File System Access API & File API:** Powering local codebase selection and directory reading in `codebase-uploader`.
- **RFC 1951 (DEFLATE Compressed Data Format):** Algorithmic basis for client-side raw deflate stream compression in `chatgpt-conversation-bridge`.
- **PKWARE ZIP File Format Specification:** Providing file header layout, local file descriptors, and central directory structures for zero-dependency archive creation.
- **ISO/IEC 29500 / ECMA-376 (Office Open XML - OOXML):** Standard for programmatic WordprocessingML (`.docx`) document synthesis.
- **RFC 7089 (Memento Framework) & RFC 1123 (HTTP Date):** Standards for datetime negotiation and TimeMap URI resolution in `web-archives`.

---

## Userscript Managers & Ecosystem

- **Tampermonkey** by Jan Biniok: Providing rich userscript capabilities (`GM_*` APIs, storage events, and menu integration).
- **Violentmonkey**: Open-source userscript manager providing standard WebExtension compliance.
- **Greasemonkey**: Pioneering user-scripting platform and API definitions (`GM.*` promises).

---

## Preservation Initiatives & Public Archives

- **Internet Archive (Wayback Machine):** For public preservation of the global web and open Availability/CDX APIs.
- **Archive.today:** For resilient on-demand web snapshots and Memento TimeMap access.
- **Perma.cc (Harvard Library Innovation Lab):** For permanent citation preservation.
- **Software Heritage:** For the universal archive of software source code.
